Month in brief

SharePoint temporary authentication URLs retire April 1, 2027, breaking dependent automation

The period's main administrator issue is a hard dependency deadline: SharePoint temporary authentication URLs will be retired on April 1, 2027, breaking Power Apps and Automate functionality that relies on them. Unified Copilot Search is moving through preview across SharePoint Online and OneDrive for the web, while new guidance describes an off-by-default control for blocking agentic-user external sharing. A group-permission access report is rolling out from late November into early December, and an opt-in SharePoint storage-overage meter is planned for January 2027.

  • SharePoint · General
    Temporary authentication URLs retire April 1, 2027

    SharePoint temporary authentication URLs will be retired starting April 1, 2027. Power Apps and Automate functionality that relies on them will break when the URLs are retired.

  • SharePoint · AI and Copilot
    Unified Copilot Search moves from preview toward general rollout

    SharePoint Online and OneDrive on the web are updating to a unified Copilot Search experience with natural-language prompts, AI summaries, and filters. Preview rollout started in mid-October 2026, with general rollout scheduled for mid-January 2027. Users can opt out during preview, and the notice says minimal organizational action is required.

  • Agents and Copilot · Permissions and governance
    Tenant policy can block agentic users from external sharing

    New SharePoint and OneDrive guidance describes a tenant-level policy that blocks agentic users from sharing content with external users. It is off by default and can target all agentic users or users associated with selected application blueprints through SharePoint Online PowerShell.

  • SharePoint · Reports and usage
    Group-permission access report arrives in the SharePoint admin center

    The Data access governance report for group permissions is rolling out worldwide from late November to early December 2026. It identifies sites accessible to specific groups and helps assess access levels, supporting checks for unintended content exposure.

  • SharePoint · Licensing and billing
    Opt-in meter adds pay-as-you-go billing for storage overages

    A global January 2027 rollout will offer an opt-in pay-as-you-go meter for storage used beyond the included SharePoint quota. The meter integrates with Microsoft 365 Archive and requires Azure billing permissions.

For SharePoint and OneDrive administrators

Inventory Power Apps and Automate dependencies before April 1, 2027. Copilot Search requires minimal organizational action, and users can opt out during preview. The external-sharing policy is off by default and can be scoped through SharePoint Online PowerShell. Use the group-permission report to investigate site exposure after rollout; the storage meter is opt-in and requires Azure billing permissions.
