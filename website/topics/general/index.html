Latest General changes

18 November 2026

Microsoft 365 Backup: Full workload backup for SharePoint, OneDrive, and Exchange

Message CenterMC1387526 on mc.merill.net ↗Plan for change
General

Microsoft 365 Backup introduces Full Workload Backup for SharePoint, OneDrive, and Exchange, enabling admins to protect entire workloads with a single policy. Rolling out from July 2026 (preview) to February 2027 (general availability), it automates backup of all artifacts while preserving existing policies and allows exclusions via CSV.

17 November 2026

How shareable links work in OneDrive and SharePoint in Microsoft 365 - SharePoint in Microsoft 365

General

The article now distinguishes direct access from link-based sharing and explains hero links, audience scopes, forwarding, authentication, and access through search or Copilot. It also updates diagrams, links, and metadata.

17 November 2026

Microsoft OneDrive for iPad: Presentation mode for PDFs

Message CenterMC1558041 on mc.merill.net ↗Stay informed
General

Microsoft OneDrive for iPad will introduce a presentation mode for PDFs, enabling a focused, view-only experience that disables free scrolling to prevent accidental page changes. Rolling out worldwide in December 2026, it is enabled by default with no admin controls required and does not affect file permissions or compliance.

17 November 2026

Microsoft OneDrive for Windows and Mac: node_modules folders will be excluded from sync by default

Message CenterMC1558030 on mc.merill.net ↗Major updatePlan for change
General

Starting December 14, 2026, OneDrive for Windows and Mac will exclude new folders named "node_modules" from syncing by default to improve performance. Existing synced folders remain unaffected. Administrators can disable this exclusion via policy if needed. No user prompts will occur, and local folder use continues.

17 November 2026

OneDrive transitions to the cloud.microsoft domain

Message CenterMC1392563 on mc.merill.net ↗Stay informed
General

OneDrive is transitioning its URLs from contoso-my.sharepoint.com to onedrive.cloud.microsoft, starting September 2026 and completing by September 2027. Both domains will coexist indefinitely, with no changes to file access or APIs. Admins should review custom solutions and update documentation; no immediate action is required.

17 November 2026

Sync Release Notes

General

The release notes now list newer Production builds—26.204.1019.0009 and 26.212.1029.0006—released November 13, 2026, with product issue fixes intended to improve sync reliability and performance.

16 November 2026

Changes to site logo URL metadata in SharePoint search results

Message CenterMC1556092 on mc.merill.net ↗Major updatePlan for change
General

SharePoint will change how site logo URLs are updated in search metadata, stopping automatic updates of the SiteLogoUrl property on individual items. Rollout is from December 2026 to March 2027. Organizations using this property in search results should retrieve logos directly from the site instead.

14 November 2026

Sync Release Notes

General

The documentation adds November 2026 OneDrive builds and describes syncing pausing during Windows Game Mode and resuming afterward. It also records reliability and performance fixes for recent Windows and macOS releases.

13 November 2026

Microsoft SharePoint: Resources web part and Announcements capabilities expand to all sites

Message CenterMC1552397 on mc.merill.net ↗Stay informed
General

The Resources web part and Announcements capabilities are expanding to all SharePoint sites, allowing site owners to share links and updates more flexibly. Rollout starts mid-November 2026 worldwide and mid-December 2026 for GCC/DoD, with no admin action required.

13 November 2026

Power Platform - Information regarding the end of support for SharePoint temporary authentication URLs

Message CenterMC1551122 on mc.merill.net ↗Stay informed
General

Starting April 1, 2027, SharePoint temporary authentication URLs will be retired. Power Apps and Automate functionality that relies on these URLs will break when they are retired.

11 November 2026

Trim Versions

General

The article was revised with clearer wording, identifies SharePoint Administrators as able to queue trim jobs, and simplifies the What-if and manual expiration guidance. It now highlights the 30-day minimum and removes the previous text about versions created before January 1, 2023.

9 November 2026

Microsoft OneDrive and SharePoint: Annotate sensitivity-label protected PDFs on the web

Message CenterMC1545696 on mc.merill.net ↗Stay informed
General

OneDrive and SharePoint on the web will allow users with editing rights to annotate sensitivity-label protected PDFs without removing labels. Annotations and protections are preserved upon saving. This feature rolls out worldwide in late January 2027, requires no admin action, and applies only to OneDrive for Business and SharePoint.
