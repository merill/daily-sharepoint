Data Access Governance Reports

20 November 2026Feature update+10 / −5 lines

In brief

The report is documented as supporting either specified users or Microsoft 365 and Microsoft Entra security groups. User reports include direct and indirect item access counts, while group reports show items shared directly with the group.

What SharePoint admins need to know

Administrators can assess site access for groups as well as users and should interpret group results separately because indirect permissions are excluded.
