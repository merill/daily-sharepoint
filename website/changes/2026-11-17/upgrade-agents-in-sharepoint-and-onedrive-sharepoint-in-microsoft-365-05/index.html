Upgrade agents in SharePoint and OneDrive - SharePoint in Microsoft 365

17 November 2026RetirementAction required+33 / −17 lines

In brief

The documentation says the upgrade experience begins rolling out in mid-November 2026. Existing .agent files used in Teams or Microsoft Copilot will stop responding until upgraded; Teams chats require upgrading all agents together. The SharePoint Agents icon and Main agent setting will also be removed.

What SharePoint admins need to know

Identify affected agents and plan upgrades. For Teams chats, remove the old agent and add the upgraded agent; verify user access to the agent and its knowledge sources.

What is changing?

Microsoft is upgrading the agent experience in SharePoint and OneDrive. Upgrading better aligns your agents with the Microsoft Copilot extensibility ecosystem, ensuring your agents are part of the Microsoft Copilot app Home experience and the Microsoft plugin registry, the shared catalog for discovering, publishing, and governing organization-approved and custom-built plugins across Microsoft Copilot experiences, Microsoft 365 apps, OneDriveOneDrive, and SharePoint.

Existing agents in the .agent file format will continue to work across SharePoint, Microsoft Teams, and the Copilot app until the end of March 2027. You can start upgrading or moving each experience to a supported path that best fits its purpose now. After March 2027, .agent files will stop responding and you will have to upgrade to continue using them.

| Provides a customized Q&A, retrieval, or analysis experience | Upgrade the agent with Microsoft Copilot Agent Builder | | Is a custom engine agent built in Copilot Studio and published to SharePoint | Publish the existing Copilot Studio agent to Microsoft Copilot app |

Starting in mid-November 2026, you'll use Microsoft Copilot Agent Builder to create agents for SharePoint and OneDrive. You can still select SharePoint and OneDrive content as knowledge sources and use a provided prompt to start building a conversational agent. However, creating an agent no longer saves a .agent file in SharePoint or OneDrive. You can edit, share, and monitor your agents through the Copilot app and manage them through Agent 365Agent 365.

Are agents in SharePoint and OneDrive being retired?

Agents in .agent file format stop responding to prompts:

  1. .agent files that you added to a Teams chat or channel stop responding. Users will see a message indicating it needs to be upgraded before it can be used.

  2. .agent files that you used in Microsoft Copilot app stop responding. Users will see a message indicating it needs to be upgraded before it can be used.

  3. In SharePoint and OneDrive:

    • Accessing a .agent file (directly or through a share link) displays a message that indicates an upgrade is required.
    • The agent no longer opens in the immersive viewer, Copilot app, or SharePoint side chat pane.
    • The agents icon on the SharePoint navigation no longer appears.will be removed.
    • The only main agent available on a SharePoint site is Copilot, so thisthe Main agent setting in the Site AI pane is no longer needed and will be removed.
