Day in brief

SharePoint agents begin requiring upgrades as OneDrive shifts to cloud.microsoft URLs

Two updates carry the most operational weight. The SharePoint and OneDrive agent upgrade experience begins rolling out in mid-November 2026, and existing .agent files used in Teams or Microsoft Copilot will stop responding until upgraded. Separately, OneDrive URLs are transitioning from contoso-my.sharepoint.com to onedrive.cloud.microsoft between September 2026 and September 2027. The other changes are primarily guidance and maintenance: Application Restrictions cmdlet availability is still rolling out, Viva Connections home-site management is directed to the SharePoint admin center, sharing-link guidance is more precise, and OneDrive Sync release notes add two production builds.

  • Agents and Copilot · AI and Copilot
    Agent upgrades will affect existing Teams and Copilot .agent files

    The upgrade experience begins rolling out in mid-November 2026. Existing .agent files used in Teams or Microsoft Copilot will stop responding until upgraded. Teams chats require upgrading all agents together, and the SharePoint Agents icon and Main agent setting will be removed.

  • SharePoint · General
    OneDrive URLs transition from SharePoint domains to cloud.microsoft

    The transition from contoso-my.sharepoint.com to onedrive.cloud.microsoft starts in September 2026 and completes by September 2027. Both domains will coexist indefinitely, with no change to file access or APIs. Administrators should review custom solutions and documentation; no immediate action is required.

  • Agents and Copilot · AI and Copilot
    Application Restrictions guidance flags tenant-dependent cmdlet availability

    The Application Restrictions cmdlets are rolling out and may not yet be available in every tenant. The page also updates all listed PowerShell links to the Microsoft.Online.SharePoint.PowerShell module path.

  • Sites and intranet · Planning and deployment
    Viva Connections home-site management is directed to SharePoint admin center

    Current setup guidance sends administrators to SharePoint admin center > Settings > Home sites to add, order, assign audiences to, and remove home sites. The Microsoft 365 admin center remains available as a legacy experience during the transition.

  • Sharing and permissions · General
    Shareable-link guidance separates direct access from link-based sharing

    The updated guidance distinguishes direct access from link-based sharing and covers hero links, audience scopes, forwarding, authentication, and access through search or Copilot. It gives administrators clearer material for evaluating internal, guest, and anonymous sharing scopes.

Microsoft OneDrive for Windows and Mac: node_modules folders will be excluded from sync by default

New

Starting December 14, 2026, OneDrive for Windows and Mac will exclude new folders named "node_modules" from syncing by default to improve performance. Existing synced folders remain unaffected. Administrators can disable this exclusion via policy if needed. No user prompts will occur, and local folder use continues.

Microsoft OneDrive for iPad: Presentation mode for PDFs

New

Microsoft OneDrive for iPad will introduce a presentation mode for PDFs, enabling a focused, view-only experience that disables free scrolling to prevent accidental page changes. Rolling out worldwide in December 2026, it is enabled by default with no admin controls required and does not affect file permissions or compliance.

OneDrive transitions to the cloud.microsoft domain

New

OneDrive is transitioning its URLs from contoso-my.sharepoint.com to onedrive.cloud.microsoft, starting September 2026 and completing by September 2027. Both domains will coexist indefinitely, with no changes to file access or APIs. Admins should review custom solutions and update documentation; no immediate action is required.
