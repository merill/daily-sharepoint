Power Platform - Information regarding the end of support for SharePoint temporary authentication URLs

13 November 2026MC1551122 on mc.merill.net ↗Message

In brief

Starting April 1, 2027, SharePoint temporary authentication URLs will be retired. Power Apps and Automate functionality that relies on these URLs will break when they are retired.

Message Center announcement

Starting April 1, 2027, SharePoint temporary authentication URLs will be retired. Power Apps and Automate functionality that relies on these URLs will break when they are retired.

How does this affect me?
Any Power Apps app or Power Automate cloud flow that relies upon the temporary authentication URLs will stop working.

What action do I need to take?
If you are using only native controls, actions, and connectors, and as long as you are not providing pre-authenticated URLs from SharePoint, then there is no action needed.

If you have authored a custom control, action, or connector with tempauth URLs, then you will need to ensure you have migrated to the new authentication. This may come up in a few ways such as:
  • SharePoint document-library thumbnails not loading
  • SharePoint-stored Images displayed through Image control not loading
  • For the Word Online (Business) connector, CreateWordFileWithContent currently returns a pre-authorized URL that can be used to download the generated document without additional authentication. After temporary authentication is removed, customers should no longer rely on this URL as an unauthenticated file-download mechanism.
After making the required changes, publish updated apps or save and publish updated flows, as applicable. Ensure the updated apps and flows are enabled and tested before the retirement date

For more information on this, visit Pre-authenticated (tempauth) URLs are retiring: move to Microsoft Entra ID tokens before April 1, 2027.
